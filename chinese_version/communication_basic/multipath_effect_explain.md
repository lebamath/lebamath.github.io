# 多径时延的影响
在无线传输中，由于环境中反射，折射等物理现象，导致多个路径的信号到达接收端，而每个路径由于无线电波走得路途的远近不同，到达接收端的时延是不同的。

现在用一个例子来演示一下。

​	   这个频率的信号，有两个路径传输到接收端，每个路径的时延分别是 0.01秒和 0.015秒，经过两路时延后收到的信号，分别显示在下图中：

​     红色：是原始发出的信号
